# GitLab Workspace 0.37.2

## 本版更新

- 對齊 WorkflowKit 1.3.1。新安裝的 BMAD 由整合包管理；輸入需求後複製提示詞到 Codex，由 BMAD 自行選擇流程，預設產物位於共用根目錄的 `_bmad-output/`。
- 共用根目錄沿用既有設定，切換時 Skills 與 BMAD 一起切換。外部 BMAD 由套件安裝器保留並標示管理模式；缺少 uv 時，安裝仍可完成並提示執行前準備環境。
- WorkflowKit 設定分別呈現版本、Skills 數量、完整性、相容性、更新與執行環境。BMAD 主機請求會重新確認目前根目錄與能力，避免舊畫面複製過期指令。
- Wiki Skills 指引新增「繪製圖表」，提供十種類型及範圍欄位；只有安裝宣告 `visualize` 能力的整合包能使用。
- 依固定的 WorkflowKit 1.3.1 附件核對 MergeReviewer 0.20.3 與 ReleaseReviewer 0.10.1；兩者未提供新版 `capabilities` 指令，改以受限的原生 session 介面回退檢查。

- VS Code Extension Host 13 項通過；3 項需另行啟用的原生 Webview／即時測試未執行。
