# GitLab Workspace 0.38.0

## 更新內容

- 新增共用 Dashboard，顯示本機專案根目錄、已發現 Repo 與本機工具狀態，並提供掃描與功能入口。
- GitLab 成為選用整合；未登入也能使用本機 Repo、Git、Skills／Wiki、分支審查與 BMAD。
- 選擇 GitLab Group 後，自動載入專案、指派給目前帳號的 Issue 與 MR 摘要；區塊使用既有快取、支援重試，並標示分頁尚未完整的狀態。
- 登出時從 GitLab 專屬頁返回 Dashboard，保留本機專案設定與 Repo 選取。

## 發布驗證

- `workspacePageLoading` 單元測試 62 項通過；Dashboard 行為測試 154 項通過；側欄行為測試 13 項通過。
- TypeScript 編譯、Webview 型別檢查、Dashboard／側欄建置、VSIX 打包與套件內容驗證通過。
