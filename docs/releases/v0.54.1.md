# 0.54.1

修正本機 GitLab 連線協調無法復原、Issue／MR 初次載入失敗後無法重試，以及私有附件存取問題。

## GitLab 連線與復原

- 確認持有程序已結束後，回收失效的 API 控制鎖；本機請求保留額度直到清理成功，避免錯誤釋放仍在使用的資源。
- 協調等待、取消與清理採有限時處理；錯誤會記錄階段、原因及請求是否已開始，方便從 Log 判斷下一步。
- 已送出但結果未明的寫入保留核對狀態，避免把清理失敗當成尚未執行而重送。
- Issue／MR 頁面初次初始化失敗後，可重新嘗試載入。

## 附件

- GitLab 17.4 以上使用目前專案的附件 API 下載。
- 舊版 GitLab 的私有附件若需要瀏覽器登入，提供「在 GitLab 查看」入口。
- 檢查附件所屬伺服器、專案及路徑，並在操作前核對目前頁面情境。

## 正式附件

正式附件為 `gitlab-workspace-0.54.1.vsix` 與 `SHA256SUMS`。發布前須通過 Windows／Python 3.11／VS Code 1.90.0、Windows／Python 3.11／VS Code stable、Windows／Python 3.14／VS Code stable 三組完整 CI 驗證；正式來源與附件摘要以 GitHub Release 的 Verification 區段為準。
