# 0.55.0

GitLab 未登入、未選 Group、Token 失效或服務無法連線時，本機工作流程仍依自己的環境條件啟用。

## 本機工作延續

- 本機 Repo 掃描、Git、Codex 及已安裝的 Skills／Wiki／BMAD 不再由 GitLab 帳號切換一併阻擋。切換帳號或 Group 時保留純本機任務、輸入、選取與閱讀狀態；更換專案根目錄及同 Repo 寫入仍保留原有保護。
- GitLab 連線狀態區分尚未設定、尚未驗證、正在連線、已連線、需要重新登入及暫時無法連線。單一資源權限不足或可選探測失敗，不會停用本機功能；重新登入的身分不符也不會覆蓋原有效帳號。
- Git 遠端操作固定本次認證與目的地，支援不同的 Fetch／Push 網址；操作途中不改用另一個帳號的 Token，外站遠端保留其獨立 Git 認證。

## 成果與草稿

- 尚未封存的 GitLab 關聯報告、交接文件與 Wiki 草稿可在原專案唯讀閱讀與匯出；原帳號、來源版本及任務歸屬保持不變。
- 成果清單、文件閱讀、複製摘要及匯出不初始化執行服務、不觸發模型或任務清理。永久成果包沿用完整匯出，接續摘要保留牌卡與成果位置。
- 本機與遠端輸入分別保存，本機草稿依工作區與實際根目錄延續，遠端回答／留言依原帳號隔離。能確認歸屬的舊輸入保留原件與衝突；刪除紀錄及待確認送出收據不會被轉成新操作。
- 冷啟動載入的未完成本機任務，可由使用者明確核對狀態後接續；唯讀成果不提供遠端執行或發布權限。

## 使用條件與驗證

Codex 仍需要自身登入、模型服務及必要工具。下載 WorkflowKit 需要其 GitHub／Gitea 來源可達；Git 遠端操作仍需要該遠端可達與有效 Git 認證。本版不建立 Issue／MR 離線資料庫或自動發布佇列，Workspace Trust、虛擬工作區與跨視窗擁有權限制保持適用。

功能實作完成後的本機 `test:ui` 已通過：2,034 項單元測試成功、4 項既有跳過，426 項介面行為測試成功，原生 Extension Host、12 組縮放／佈景主題、Workspace Trust、渲染效能與封裝檢查通過。正式附件由本次提交的完整 CI 矩陣產生並核對；本機驗證不代替正式 CI 證據。GitLab／模型情境使用 fixture，未執行人工 Screen Reader 驗收。

本次發行同時包含尚未正式發布的 0.54.3 本機 API 控制復原入口，以及前次完整驗證工具整理。附件為 `gitlab-workspace-0.55.0.vsix` 與 `SHA256SUMS`。詳細功能條件見[GitLab 不可用時的功能](../gitlab-independent-workflows.md)。
