# GitLab Workspace 0.41.0

本版串接 Issue 開發、GitLab Wiki 與一鍵 MR 審查。任務記錄綁定 GitLab 帳號、專案、Repo 及來源版本，原功能頁可查看成果，Codex 頁可返回來源；原有 Skills 與 BMAD 進階入口保留。

## 變更

- Issue 預覽與詳情新增「使用 Codex 開發」。從同步後的遠端預設分支建立唯一 Issue 分支，由 BMAD 選擇流程並完成實作及測試。未提交變更會阻擋啟動，重複點擊沿用進行中任務；規格完成後可接續實作，成果須有實際差異及成功測試命令。
- 專案新增「建立／更新 Wiki」。以固定 SHA 的 archive 快照分析，先預覽 `codebase/` 頁面再手動發布；轉換文件及程式來源連結，保留逐頁寫入收據，支援遠端衝突、部分失敗及逾時對帳。
- MR 詳情新增「一鍵 Code Review」。自動取得 Repo 與固定來源／目標版本，直接交給 MergeReviewer；原生收據須確認版本及審查完整性，才顯示成果就緒。報告回填原 MR 並預填空白留言草稿，發布前再次核對版本。
- 共用 Skills 使用 CLI `skills/extraRoots/set`，分開記錄安裝根、目標 Repo 與執行目錄；保留跨視窗執行鎖及寫入保護。新來源任務的程序收尾最多等待 30 秒，無法確認停止時保留執行鎖。
- 沿用前版後續的 Codex 統一管理與逐任務 Auto-Accept，保留手動核准、暫停及恢復。提交、推送、Wiki 發布與 MR 留言仍由使用者操作。

## 使用需求

三個 GitLab 來源入口需要 Codex CLI 0.166.0 或更新版本、可用的 Windows sandbox、已登入 GitLab、已對應的本機 Repo 與已安裝的 WorkflowKit。原有手動入口仍保留。

## 驗證與限制

- 本機 Host／Webview 型別、Lint、246 項 UI 行為、39 個 Cucumber 情境及相關 Extension Host 測試已通過；最後功能增量回歸 52 項通過。正式附件由完整 GitHub Actions 矩陣驗證後發布。
- 真實 Codex Issue 測試可從暫停恢復，完成修改與實際測試，沒有自動提交或推送。真實模型產生的 6 頁 Wiki 已通過獨立草稿收集及預覽檢查，預覽遠端寫入為零。
- GitLab CE 16.11.10 真實發布與 MR 留言尚未驗收：本機 instance 可連線，但所提供憑證回傳 401，沒有進行遠端寫入。API 契約、衝突及對帳已以模擬遠端驗證。
- 一次隔離 Wiki 長任務未取得程序停止收據，任務與鎖保留為待核對。新程序的獨立停止收據檢查通過；此結果不代替完整長任務的實機驗收。
- 本機舊版安裝器完整矩陣曾主動中止，不計為通過；正式 Release 仍須通過既有 CI 完整矩陣。
