# GitLab Workspace 0.58.2

- 還原最大化的整合終端後，GitLab Workspace 會回到原本的工作台頁面，並保留草稿和操作進度。
- 在 Skills、BMAD 或審查工作按「使用 Codex 執行」後，選完模型會在工作終端預填 `codex`。你可以先開啟 Auto-Accept，再按 **Enter** 啟動。等待期間可關閉終端取消。
- 本機 Windows 會自動偵測 Microsoft Store 版 PowerShell。等候模式需要 VS Code 1.93 以上、Terminal Shell Integration 與 PowerShell 7.3 以上。若要直接啟動，可在 VS Code 使用者設定將 `gitlabWorkspace.codex.waitForEnter` 設為 `false`。

完整設定與操作步驟見 [Codex CLI 操作說明](../codex-cli.md)。
