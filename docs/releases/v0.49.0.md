# 0.49.0

Reviewer 改為固定模型與思考強度，移除 Auto 評估、自動升級及路由子代理。建立任務時使用模型目錄提供的強度；CLI 提示詞沿用目前 CLI 設定。新 Host 搭配舊 Kit 也明確停用路由。

移除 Tree-sitter 語法分析綁定、啟動資產檢查與相關任務提示。新建、複製及恢復任務重建提示詞時，僅使用目前支援的 runner 欄位。搭配 WorkflowKit 1.9.0，Reviewer 與 Wiki 使用原生來源讀取流程。

所有原生 Reviewer 入口都在模型回合結束後檢查固定 request 的報告收據；尚未發布時，在同 thread／模型／強度內接續最多兩次，沒有保存進展則保留待續狀態。已發布而有必要缺口的報告直接交付，不再重跑。

舊 routing request 先驗證原生身分，再沿最後保存強度續作；歷史 routing JSON 不改寫為完成。尚未選定強度、已終止或派送不明者保留明確恢復入口。診斷匯出新增每個回合的派送設定、thread／turn、時間及可觀測模型資訊。

配套版本為 WorkflowKit 1.9.0、MergeReviewer 0.22.0；效能數據見套件驗收紀錄。
