# GitLab Workspace 0.35.0

## 本版更新

- 工時未指定日期時使用送出時間；指定日期轉為使用者本機時區當日零時。GraphQL 請求提供必要的時間與摘要欄位，並以 timelog ID 確認建立。
- 工時明確未寫入時保留輸入與錯誤，可由使用者修正後重試；成功後避免重複送出，結果不明時維持對帳流程。寫入不會自動重送。
- Issue 刪除依最新專案資料確認 Owner 權限，支援繼承的 Group Owner 與個人專案擁有者；確認後再次檢查權限。
- MR 立即合併依 GitLab 回報的使用者權限、Draft、衝突、rebase、合併狀態與已審查 SHA 判斷，確認後重新核對。條件未確認或不允許時顯示原因，並提供手動重新檢查及 GitLab 入口。

## 驗證與限制

正式附件由 GitHub Actions 完整 CI 矩陣測試並驗證 VSIX 與 SHA-256 後發布。

已在隔離的 GitLab CE 16.11.10 透過擴充功能 API 客戶端驗證工時、繼承 Owner 刪除 Issue，以及以審查 SHA 合併 MR。Extension 與官方 GitLab 網頁的畫面操作比對、其他角色的實機驗證及實際斷線情境仍待完成；詳見[驗證紀錄](../work/work-20261027-gitlab-ce-parity/validation.md)。
