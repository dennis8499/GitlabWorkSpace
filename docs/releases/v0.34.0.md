# GitLab Workspace 0.34.0

- 移除「開啟 Codex CLI」按鈕與各平台啟動邏輯。複製提示詞後，請自行在畫面顯示的專案根目錄啟動 Codex，再貼上執行；舊版工作台送出的啟動請求會被拒絕。BMAD 一般專案終端、指令複製及環境檢查保留。
- MR 的 Reviewer／指派篩選交由 GitLab Server 處理。差異以固定版本與 SHA 核對，五分鐘內可跨選取重用；手動更新仍會重新確認版本。
- Issue 專案搜尋、成員、標籤及里程碑採按需分頁，切換條件會取消舊讀取，保留草稿與已選值。
- 清楚呈現載入、部分清單、空結果、錯誤、資料來源及取得時間；排隊與限流顯示傳輸階段及重試時間，倒數到期不會自動發起請求。
- 改善抽屜、對話框、通知與頁面切換的鍵盤焦點及過場，支援減少動態效果。新增「GitLab Workspace: 設定」命令，登入完成後清除表單中的 Token。
- 本機 Git 依變更範圍失效快取，單純 Stage 不重讀歷史、Refs 或 Config；最近 Fetch 時間只記錄工作台觀察到的成功操作。

本版沿用獨立發行的 WorkflowKit 與既有安裝契約；不要求上游 Skills 同步改版。

## 驗證與限制

正式附件由既有 Linux／Windows、Python 3.11／3.14 與 VS Code 1.90／stable 的四組 CI 矩陣驗證後發布，包含完整測試、VSIX 內容與 SHA-256 核對。

GitLab CE 的驗收目標為 16.11.10，新增版本釘選合約與精確版本測試設定。這些合約使用合成範例；已登入的 CE 16.11.10 實機驗收及原生 Commit／Push modal 人工驗收仍待完成，沒有以模擬或測試 adapter 的成績替代。詳細證據與既有限制見 [UI／UX 與按需連線改善驗證](../work/work-20261023-demand-ux/verification.md)。
