# GitlabWorkSpace 0.47.0

Codex 的來源、準備、執行、檢閱及交接整合為同一條工作流程。

- 新增可保存的任務準備頁，頁內選擇 Repo、模型、思考強度及 MR 討論。環境修復後接續原草稿，開始執行前才建立任務。
- 重新檢查會列出來源前後版本、Issue 更新時間及討論變更，確認更新後才能開始；已停止的 GitLab 任務可保留需求另開準備，原任務與其他草稿保留。
- Issue 預設使用隔離 worktree，工作根目錄、BMAD 產物、程式修改及測試維持一致；既有任務沿用原位置。
- 工作台分成執行與成果，固定待回答區與輸入框，提供階段、阻塞原因、主要下一步及詳情。窄版改為任務選擇器。
- `gitlabWorkspace.codex.workspaceLayout` 可即時切換工作台與傳統同頁排列；只回退版面，沿用相同任務控制與草稿，不重送工作。
- 回答、MR 回覆及未送出的準備內容可恢復。跨視窗修改使用 revision、檢查所有權與 preparation generation 防止舊資料覆寫及舊快照提交。
- 非秘密草稿依帳號與專案保存到本機，可跨工作台關閉與 VS Code 重啟恢復；逐筆版本核對保留衝突副本，恢復不會重送操作。
- Agent、報告及 Wiki 支援安全 Markdown、程式碼複製及檔案行號導覽；Wiki 提供原文／差異及變更頁篩選，Issue 交接草稿直接在成果頁檢閱。
- 排隊、準備及等待回答期間可保存補充需求，持久 outbox 追蹤送達結果；結果不明時先核對，不自動重送。
- 修復多任務同時暫停時偶發停在待核對。
- App Server 保留逐任務程序與停止收據，新增執行檔／模型／環境快取、合併重複查詢、按任務載入與帶 revision 的畫面增量更新。
- 完整旅程診斷記錄準備、排隊、啟動、首次回覆、成果驗證及清理耗時；只記錄必要數值與識別，不記錄提示詞或機密。

操作方式見 [Codex 任務工作台](../codex-bridge.md)，驗證範圍與畫面見 [實作驗證紀錄](../work/work-20261110-codex-workspace/verification.md)。本機候選安裝包不代表已發布；正式發布仍需對應提交的 CI 矩陣。
