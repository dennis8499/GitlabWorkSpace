# GitLab Workspace 0.33.0

- WorkflowKit 改為獨立 Repo 與版本，Extension 透過 GitHub 或指定的 Gitea Release 安裝。
- 設定頁顯示目前版本與最新相容版本；使用者手動檢查、下載及安裝，並顯示各階段進度。
- 移除 VSIX 內附整合包、本機 ZIP 匯入及本機套件選單。下載後驗證附件大小與 SHA-256，再執行同一 Release 的安裝器。
- Skills 依契約、profile、capabilities 與內容驗證判定可用性。有更新時仍可使用目前相容版本。
- 保留既有安裝標記與 0.32.0 升級支援；舊 bundled 來源設定轉為 GitHub。
- 工作區使用 Skills／Extensions 分類，各自探索直接子 Repo；整合包更新不再要求 Extension 同步改版。

WorkflowKit 首版為 1.0.0，沿用目前上游版本。本次改動沒有宣稱改善上游模型審查品質或效能；既有品質驗收結果維持原紀錄。

Gitea 鏡像命令已提供，實際發布與下載驗收須在可解析公司內網主機的環境執行。
