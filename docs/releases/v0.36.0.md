# GitLab Workspace 0.36.0

## 本版更新

- 新增「SOP 工作流程」頁面，依 Group Issue 的 Label 辨識 User Story、Task、Change 及 Bug，提供牌卡篩選、流程詳情、關聯項目、資料補登與建立範本。類型、狀態和難度可依連線與 Group 設定。
- 驗收、Pending、退回、重開、結案及上版依階段檢查必要資料；關聯、Commit 與 MR 證據不足或無法確認時不宣告通過。Issue 的其他內容及標籤保留，流程紀錄存於版本化的 description 管理區塊。
- User Story 的流程狀態由負責人確認；執行項目的新增、重開與進度會提示重新檢查。跨專案關聯使用 GitLab Linked Items，與原生子任務分開呈現。
- WorkflowKit 保留安裝、更新和 Skills 入口，狀態查詢使用已安裝版本的驗證安裝器並保持唯讀；安裝完整性、介面相容性及更新可用性分開顯示。兩個專案依穩定契約各自建置、測試及發版。

## 驗證與限制

正式附件由此版本 commit 的 GitHub Actions 完整驗證後發布。[GitLab CE 16.11.10 驗證紀錄](../work/work-20261028-sop-ce16/verification.md)涵蓋 SOP API 與實際 Extension Host 畫面；其中實機畫面測試使用的是本版功能整合前的 0.35.0 測試 VSIX，並非 0.36.0 正式附件。

流程檢查約束工作台發出的操作；從 GitLab 網頁或其他工具直接變更後，重新讀取時會顯示目前狀態及衝突。
