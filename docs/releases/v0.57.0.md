# GitLab Workspace 0.57.0

Skills、BMAD 和審查工作可在專用的 PowerShell 7 終端預填 `codex`。先在該終端開啟你安裝的 Auto-Accept，再按 **Enter** 啟動。等待期間可關閉終端取消。

此模式預設關閉。在 Windows 的 VS Code 使用者設定將 `gitlabWorkspace.codex.waitForEnter` 設為 `true` 即可啟用。需要 VS Code 1.93 以上、Terminal Shell Integration 與 PowerShell 7.3 以上。可攜式 PowerShell 可透過 `gitlabWorkspace.codex.pwshPath` 指定。詳見 [Codex CLI 操作說明](../codex-cli.md#先開啟-auto-accept-再啟動-codex)。

按 Enter 後，GitLab Workspace 會重新核對工作區與審查版本，並取得本次工作所需的執行鎖。工作收尾依 Codex 程序的實際退出結果處理。
