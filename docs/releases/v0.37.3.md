# GitLab Workspace 0.37.3

## 更新內容

- MergeReviewer 與 ReleaseReviewer 會讀取安裝版 Reviewer 的平行 Agent 能力；只有明確回報支援時才顯示平行模式與子 Agent 設定。
- 能力缺漏或未支援時，頁面說明本次審查採單一 Agent。既有平行設定會保留，但本次提示會改用單一 Agent，並忽略子 Agent 的模型與推理強度。
- 明確支援平行 Agent 時仍可產生平行審查提示，最多使用兩個 Agent。
