# GitLab Workspace 0.32.0

發布日期：2026-10-23。由正式版 0.30.1 升級，包含 0.31.0 與 0.32.0 候選版的累積更新。

## 本版更新

- 整合 MergeReviewer 0.19.0 與 ReleaseReviewer 0.8.0 的可恢復請求、本機狀態、取消、草稿修正及報告入口。
- 兩種 Reviewer 使用各自的型別、runtime、固定證據與完成判斷；報告已發布時仍保留未完整或未知狀態。
- 合併審查支援有界並行同步及契約邊界；上版檢查保留七類部署依賴、獨立的 runtime 與來源驗證。
- 工作流程包使用經驗證的正式上游附件、固定提交與內容摘要；Wiki 維持 0.6.4，Megin 仍可獨立使用。
- VSIX 與組合 ZIP 提供相同雙 profile payload，沿用受管理 Skills 的升級與交易回復，保留既有報告及人工 Checklist。

## 已接受的驗收限制

本次依使用者於 2026-10-23 明確接受限制的決定發布正式版。原候選版的正式模型品質／效能驗收仍為未通過，沒有將原紀錄改為成功。完整自動化 CI、來源釘選、套件一致性及雙 profile 升級／回復仍是必要發布條件。

- 原效能目標為大型案例 6/6 有效配對且端到端 candidate/base 耗時比中位數不超過 0.70。MergeReviewer 為 4/6、0.9840；ReleaseReviewer 為 4/6、1.1547，兩者均未達 30% 改善目標。
- 兩個 Reviewer 合計 48 次最終 agent 執行取得 47 份報告；另一次無報告失敗仍保留，不能宣稱 48 次完整審查均成功。
- 靜態品質及情境 oracle 的未達項保留原判定；helper／Git／搜尋計數不能替代模型品質或端到端速度驗收。
- 既有 VS Code CLI 隔離安裝、installed-resources 完整流程／升級／rollback 及固定深度測試已執行；Native UI 與 production activation 未驗證。

原始驗收結果與本次接受限制的發布決策分開保存；GitHub Release 另附正式來源提交、完整 CI 與正式附件 SHA-256。
