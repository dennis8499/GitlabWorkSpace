# GitLab Workspace 0.58.4

- 執行 Reviewer 能力檢查前，核對 WorkflowKit 安裝紀錄和管理中的檔案。未能確認安裝時可從「工具與環境」重新檢查。
- 恢復執行中的原生審查時會聚焦該次工作終端。MergeReviewer 和 ReleaseReviewer 可同時審查同一 Repo 或 MR。
- Repo 清單刷新的結果會反映新登錄的 Repo。PowerShell 自動搜尋會使用目前安裝的版本，終端預設等待 Enter。
- 搭配 WorkflowKit 1.12.6 使用 ReleaseReviewer 0.12.7。已停止的遠端擷取可在取消或下次同步時回收本次暫存 Git ref。
