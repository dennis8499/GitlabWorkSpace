# 0.50.0

整合 VS Code 原生操作與工作台 UI／UX，縮短尋找專案、開啟 Issue、查看差異及啟動 Codex 任務的操作路徑。

## 操作與導覽

- 主導覽整併為「總覽、專案、我的工作、待審查、版控、Codex、工作流程」，Skills／BMAD 位於工作流程；窄視窗改用原生 Quick Pick。
- 資料夾、帳號、Git Repo／分支及 Skills 分支使用原生選擇器，保留新分支文字輸入。原生側欄可直接載入更多工作項目或重試。
- Issue 單擊開完整詳情，另保留快速預覽；從專案建立 Issue 自動帶入專案。關聯 MR 在工作台開啟，返回時保留 Issue 草稿與清單位置。
- 專案根目錄直接開啟原生資料夾選擇器；通知可返回任務、Issue／MR、環境修復或 Log。

## Git 與差異檢視

- 本機 Git、MR 與 Wiki 差異改用原生唯讀 Diff；Wiki 原文可開啟原生 Markdown 文件。MR 使用已核對版本的 base/head SHA，不依目前分支重建差異；讀取失敗保留 patch 與 GitLab 入口。
- 已確定 remote 的 Fetch 一擊執行，多 remote 使用原生選擇器。一般 Commit 直接提交已檢視的暫存內容；分支、HEAD 或暫存內容變更時停止並保留提交訊息。
- 部分暫存、Amend、Push、Pull 與破壞性操作仍保留對應入口及必要確認。差異快照維持唯讀、容量限制與分頁關閉釋放。

## Codex、Skills 與介面

- 統一「來源 → 任務準備 → 開始」；模型與成功檢查收合為摘要，隔離工作目錄設定集中準備頁。原生清單可恢復多份準備草稿，環境修復後返回原草稿，明確開始才派工。
- Skills／BMAD 以「使用 Codex 執行」為主要操作；複製與終端保留於其他方式，剪貼簿忙碌不再阻擋任務準備。保留草稿衝突、來源重檢、審查完整性與結果不明的核對流程。
- 統一 VS Code 主題、焦點及按鈕樣式；工具與訊息抽屜使用 HTML 原生 dialog。動畫同時遵循作業系統及 VS Code 減少動態效果設定。

## 效能與驗證

Git、圖譜、Skills、BMAD 與 Codex 畫面按需載入，控制器、草稿與背景事件保持接收。首屏 JavaScript 從 631,836 降至 367,799 bytes，減少 **41.8%**；這代表首次載入量，並非端到端執行速度改善百分比。10,000 筆訊息渲染 p95 約 32ms，與基線接近。

本機驗收包括 1,389 項單元、321 項行為、40 項 BDD 情境、17 項安裝／升級／回復整合測試，以及 216 個畫面場景。VS Code 1.90／1.146 各 12 個原生縮放場景通過；人工 NVDA、真實 GitLab 寫入與付費模型回合未執行。

正式附件由 GitHub Actions 完整 Windows／Python／VS Code 矩陣驗證後發布，沿用 VS Code `^1.90.0`、GitLab CE 16.11.10 及既有 Codex／WorkflowKit 契約。
