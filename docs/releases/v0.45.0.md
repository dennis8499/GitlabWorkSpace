# GitlabWorkSpace 0.45.0

Codex 與 WorkflowKit 資源依擁有者及使用生命週期清理；刪除對話會一併清除擴充功能儲存區內的附屬資料，保留原專案成果。

- 任務、環境檢查、模型清單與歷史讀取所建立的 App Server 在操作結束後停止；借用執行中任務連線的讀取由原任務管理。停止收據在鎖、排程及任務狀態完成保存後清除。
- 刪除紀錄包含 globalStorage 內的舊版備份、來源快照、Wiki 草稿及隔離 worktree。確認視窗明示隔離目錄的未提交修改也會移除；原 Repo 的檔案、分支提交及報告保留。
- 刪除先保存清理清單並阻止延遲回寫；中斷或占用後可在啟動或「重新讀取」時重試。Wiki 增量任務保存自己的前版種子；發布結果未明時阻擋刪除。
- Wiki 來源壓縮包與 WorkflowKit 安裝包用畢清理。共用驗證工具依安裝根目錄及檔案雜湊保留到最後一份引用解除；跨視窗使用權、未知歸屬及重新導向均受到保護。
- 自由任務、Skills、BMAD、Issue、Wiki 與 MR 入口可在建立前選擇模型及思考強度，選項取自 App Server 的模型清單；取消選單保留草稿。

必要的防回寫標記與操作去重收據仍保留。安裝包清理後，再次安裝需要連線下載；已安裝版本的離線狀態檢查使用保留的驗證工具。Codex 自身的對話、登入與設定資料保留。

本機完整驗證已通過：1,232 項單元、255 項 Webview 行為、原生 Extension Host、工作區信任、發行整合及 VSIX 驗證。正式附件由本版本提交的 GitHub Actions 完整矩陣產生，發布時核對來源 Commit 與附件 SHA-256；本機驗證不替代正式 CI 證明。

詳細行為見 [Codex 工作台文件](../codex-bridge.md)。
