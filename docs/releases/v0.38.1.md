# GitLab Workspace 0.38.1

## 更新內容

- 對齊 WorkflowKit 1.3.5，使用安裝根目錄的 `run.py` 啟動 helper runner。
- 從已驗證的 WorkflowKit 受管檔案清單核對 runner SHA-256；Reviewer 能力探測、舊介面探測與取消操作皆沿用 Python 設定和參數陣列。
- 將 runner 摘要納入 Reviewer 能力快取鍵；保留 Reviewer 的外部 `--runtime-root` 與兩種審查工作階段隔離。
- Wiki 與 BMAD 提示詞依 Group／Repository profile 帶入 runner 指引；未宣告 runner 的舊套件維持直接執行。
- 固定 1.3.5 正式測試附件、來源摘要及 profile 能力快照。WorkflowKit 1.3.5 同時修正 Wiki 圖表在 Windows 禁止 hard link 環境的輸出相容性。
- 升級與 rollback 驗證涵蓋 Wiki、審查報告、人工 Checklist 及 BMAD 使用者產物保留。

## 驗證

- 完整 `npm.cmd test` 通過：Extension Host、單元測試 919 項通過／3 項略過、Behavior、Cucumber、Release 整合及 VSIX 驗證。
- Release 整合的 16 項 WorkflowKit 安裝、能力、Reviewer 操作、升級與 rollback 測試通過。
- VSIX 驗證確認安裝包維持線上安裝橋接，不包含 WorkflowKit 套件附件。
- 發版標籤 CI 會針對確切版本與 main 提交重新驗證，通過完整矩陣後發布 VSIX 與 SHA-256 清單。
