# GitLab Workspace 0.58.1

Windows 先寫妥擁有者資料，再發布 Git、GitLab API、Codex、WorkflowKit 與 BMAD 使用的本機鎖。擁有者意外退出後，下一項作業會核對程序建立時間、目錄身分及程序樹的完成證據，再決定是否接手。

WorkflowKit 背景維護會把未確認的附件鎖記錄在 GitLab Workspace Log。安裝實際受阻時可在 Log 核對鎖路徑與原因。舊版遺留或缺少證據的鎖可依[離線復原流程](../codex-cli.md#復原本機工作流程鎖)檢查。

本版在 Windows 驗證了 VS Code 的直接啟動、PowerShell 終端按 Enter 啟動，以及與新版和舊版 Reviewer 共用 Git 鎖的行為。
