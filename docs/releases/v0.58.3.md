# GitLab Workspace 0.58.3

- 同一個 VS Code 視窗可對同一 Repo 或 MR 同時執行 MergeReviewer 和 ReleaseReviewer。每項工作有自己的終端和狀態。
- 執行失敗後可在工作流程頁或 MR 詳情重設該項執行。已終止的原生審查可重新同步並建立新請求。
- 模型選單先提供沿用 CLI 設定，模型清單在背景載入。複製審查提示詞會重用有效的 Repo 清單。
- 搭配 WorkflowKit 1.12.5 安裝包含 Windows Git 鎖修補的 Reviewer。詳見 [Codex CLI 操作說明](../codex-cli.md)。
