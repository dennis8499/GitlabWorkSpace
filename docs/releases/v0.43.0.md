# v0.43.0

Codex 工作台新增自由任務、可選兩項併行與完整的復原入口，並擴充 Issue、MR 討論及 Wiki 的成果交接。

- 程序關閉有明確期限；損壞紀錄逐筆隔離，派發識別與停止收據可供核對，避免重送結果不明的工作。
- 顯示執行計畫、工具、差異、模型與用量；支援任務搜尋、篩選、重新命名、釘選、封存及診斷匯出。
- 原生選單可建立自由任務，加入選取文字、文字檔或 Git Diff 快照，並選擇本次模型與思考強度。
- 併行預設 1，可設為 2；跨視窗共用名額與實體資源鎖，同 Repo、共用 runtime 及 worktree 保持互斥。
- Auto-Accept 預設 OFF，可細分命令、檔案修改與額外權限；問題、表單及登入連結維持人工處理。
- Issue 可使用隔離 worktree，交接測試證據、CommitReviewer 與 MR 描述草稿；移除 worktree 時也保護 Git 忽略檔案。
- MR 討論可固定版本建立修正任務與回覆草稿；Wiki 可依完整來源映射保守地增量重生。
- 對話分支、原生 Goal 及額度介面依 CLI 契約啟用，目前驗證基準為穩定版 CLI 0.166.0；目標模式需設定預算。

提交、推送、建立 MR、留言與 Wiki 發布仍由使用者明確操作。使用方式見 [Codex 工作台文件](../codex-bridge.md)。

功能實作階段的本機驗證為 1,198 項單元通過（3 跳過）、255 項行為通過、39 個 Cucumber 情境、42 項發行工具及 17 項 Python 安裝整合通過。兩版 VS Code 的原生功能、工作區信任及獨立監看測試通過；10,000 筆對話批次更新 p95 為 31.9 ms。[本機驗證紀錄](../work/work-20261107-codex-evolution/verification.md) 保留原始失敗、重跑及未覆蓋項目。

正式安裝附件由版本提交的完整 GitHub Actions 矩陣產生，Release 會列出來源 Commit、驗證流程與附件 SHA-256。本機測試紀錄不替代正式 CI 證明。

真實 GitLab 與模型端到端驗收另行安排；NVDA 與實際桌面縮放的人工驗收尚未完成。
