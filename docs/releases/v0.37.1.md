- 套用範本只替換 Issue 描述，保留標題、負責人、標籤、里程碑與日期。
- VSIX 排除工作區根目錄的 `GitLab_Issue_Board_使用_SOP.md`。
- 調整 Windows runner 的主機請求速率測試容差，避免排程計時誤差造成誤判。
