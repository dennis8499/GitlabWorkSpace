# GitLab Workspace 0.58.8

- MergeReviewer 和 ReleaseReviewer 可共用 WorkflowKit 狀態檢查。切換或隱藏頁面後，同一專案仍有效的 MR 審查可在原操作繼續。
- 較早的 Dashboard 檢查在新檢查啟動後失效，安裝狀態會以有效檢查的結果為準。
- 晚到的 MR 審查使用舊版 WorkflowKit runner 時，會在取得 Git 憑證前重新完整驗證受管理檔案。
- 內嵌 WorkflowKit 離線檢查會在解析完整路徑前拒絕符號連結與 Windows junction。使用內嵌檢查器時，僅在安裝紀錄有效但套件身分未知的情況查找快取檢查器。
