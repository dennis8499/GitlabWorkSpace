# GitlabWorkSpace 0.44.0

新增 WorkflowKit 1.6.0 語法能力接線，讓 Codebase LLM Wiki、MergeReviewer 與 ReleaseReviewer 的新任務、複製提示及恢復任務使用同一份受驗證的引擎身分。

- `SyntaxAnalysisBinding/v1` 綁定完整 helper／grammar／query 雜湊，能力快取納入引擎身分，執行前重新核對；舊版 WorkflowKit 沿用原流程。
- 內建唯讀安裝驗證器同步支援 WorkflowKit 1.6.0，保留舊版本狀態與相容性。Parser 二進位僅在 WorkflowKit；VSIX 增加接線及驗證資訊。
- 保留原生審查、coverage、任務恢復與 Wiki 完成規則；語法分析不能自動標記已審查。一般 Query 維持 Wiki-first，NotebookLM 仍檢查完整來源。

**Tree-sitter 增強預設關閉。** `WORKFLOW_KIT_SYNTAX_CONTEXT=auto` 僅供明確評估，需由啟動 helper 的程序繼承環境設定；既有 session 保留原讀取計畫與 operation IDs。

接線程式已完成本機完整驗證，更新的安裝驗證器亦通過歷史版本整合及重新封裝檢查。[WorkflowKit 驗證紀錄](https://github.com/dennis8499/WorkflowKit/blob/52a8f56/docs/validation/tree-sitter-1.6.0.md) 保留未完成的模型品質／效益評估，以及一項既有 Wiki 圖表瀏覽器清理失敗。正式 VSIX 由版本提交的 GitHub Actions 完整矩陣產生，Release 附件身分由該 CI 證明確認。
