# GitLab Workspace v0.56.0

從工作流程的 Skills／BMAD 或 MR 詳情的 MergeReviewer／ReleaseReviewer 啟動 Codex。每次執行可選模型與思考強度，使用 VS Code 整合終端進行互動。

此版本移除獨立 Codex 工作台及任務歷史、排程與自動核准，也移除 Issue 開發、MR 討論修正、Group 需求分析、GitLab 自動交付、MR 報告回填及 GitLab Wiki 產生／發布。一般 Git、Issue 與 MR 的原有功能繼續可用。

這是相容性變更。先前的 Codex 任務可使用 v0.55.1；本地 Wiki、原生 Reviewer 報告及 BMAD 文件仍保存在原本的檔案位置。使用方式見 [Codex CLI 指南](../codex-cli.md)。
