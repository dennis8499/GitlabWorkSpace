# GitLab Workspace 0.58.5

- 複製或執行 Wiki 等 Skills 前核對 WorkflowKit 安裝。Reviewer 可重用仍有效的安裝驗證，並重新檢查自己的檔案及套件管理的工作區指示。
- 同一 MR 的兩個 Reviewer 可共用首次 Repo 快取準備，後續各自使用固定版本、終端及重設操作。
- 搭配 WorkflowKit 1.12.7 的 ReleaseReviewer 0.12.8，可從已終止的審查重試回收本次 Git 暫存 refs。
- 每次操作對舊版 WorkflowKit 只執行一次完整驗證。開啟終端會採用當前的 PowerShell Store 註冊，預填指令在按 Enter 後執行。
