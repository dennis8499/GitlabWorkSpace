限制與待驗證

  • Windows 系統原生確認視窗的外觀待驗證：現有工具無法操作 OS 視窗。VS Code 自訂確認視窗及同一個原生 API 的操作流程已通過。
  • 實測使用 VS Code 1.139.0；VS Code 1.90 保持 API／manifest 相容，未另外執行 1.90 實機測試。
  • 同步 Clone／路徑 helper 僅保留測試相容；Windows Terminal 的有限 existsSync 檢查保留於明確開啟終端的動作。
  • 每個負載環境的 50 個 MR 未指定目前測試帳號為 reviewer，因此此負載基準不能代表大型待審查 MR 清單的延遲。
  • 有限測試與資料規模不能保證所有未來 VS Code／GitLab 版本或任意大小資料都沒有問題。
  • 冷啟動指新的 VS Code／Extension Host／使用者資料狀態；GitLab 伺服器與作業系統快取未在每次執行前重置。差異只能代表本輪測量，不能單獨歸因於特定修正。
