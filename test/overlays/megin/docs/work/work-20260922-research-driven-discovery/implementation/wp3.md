# WP3：入口、探索、規劃交接與恢復規則

狀態：`completed`

入口、探索 Skill 與技術規劃 Skill 都引用同一協定。探索 Skill 要求記錄來源、能力、決策與 revision；規劃
Skill 在交接前重新檢查來源、能力覆蓋、阻礙、介面、核心行為與驗收，不接受題數、文件存在或
`ready_for_planning` 作為完成證據。language policy 保留輸出語言與等待狀態契約，workflow record 增加
`requirements_revision` 與 `requirements_ref`。
