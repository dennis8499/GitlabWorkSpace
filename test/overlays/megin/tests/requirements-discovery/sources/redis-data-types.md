- source_id: SRC-REDIS-001

- applicable_version: Redis Open Source current documentation
- locator: Data types overview; Streams and supported native data types
- retrieved_at: 2026-09-22
- source_type: official-documentation
- certainty: recorded

摘要：官方資料型別總覽列出 strings、lists、sets、sorted sets、streams、time series、JSON 等能力，並將
Streams 描述為可追加的 log 結構。案例只使用這些分類建立探索邊界，不把它們直接轉成應用層需求。
