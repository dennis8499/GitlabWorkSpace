### GitLab Workspace workflow kit

This Git repository uses the native single-repository workflow. First read `.agents/gitlab-workspace-kit/profile.md`, then invoke the corresponding locally installed Skill. Use this repository root for Codex, knowledge, work records and helper `--workspace` arguments. The repository profile defines the scope of these tasks even when an ancestor contains a Group profile.

Megin uses its native repository lock and local delivery contract. Wiki source paths are relative to this repository. Review contexts and drafts belong in system temporary storage; final reports belong under this repository's `review-reports/`. Request JSON only when needed, and clean the owned context after completion or interruption.
