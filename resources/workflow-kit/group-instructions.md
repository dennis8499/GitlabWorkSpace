### GitLab Workspace workflow kit

For Wiki, development, and Merge Request work in this Group, first read `.agents/gitlab-workspace-kit/profile.md`. The profile binds the installed Wiki, Megin, and MergeReviewer Skills to this Group's repository layout, shared knowledge base, and GitLab delivery flow. Invoke the corresponding installed Skill for the requested work.

For MergeReviewer runs, keep contexts and drafts under system temporary storage and leave Markdown reports under their normal `review-reports/` destination. Add a JSON report only when requested. Remove the current owned context after publication or if the review stops early.
